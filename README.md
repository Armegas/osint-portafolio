# 🕵️‍♂️ OSINT Portafolio Web

Este repositorio contiene el sitio web profesional de **Nelson**, especialista en inteligencia de fuentes abiertas (OSINT), análisis reputacional y documentación técnica para investigaciones digitales y legales.

## 🎯 Objetivo

Transformar datos públicos en evidencia legal y entregables profesionales, listos para clientes, abogados, periodistas e investigadores.

## 📦 Servicios ofrecidos

| Servicio                          | Formato de entrega     | Precio desde |
|----------------------------------|-------------------------|--------------|
| Informe OSINT de riesgo digital  | PDF + anexos técnicos   | $150         |
| Auditoría de reputación online   | HTML interactivo + PDF  | $200         |
| Curso básico de ciberseguridad   | Video + guía PDF        | $50          |
| Informe técnico para abogados    | Legal + técnico (PDF)   | $300         |

Cada servicio incluye:
- Resumen ejecutivo
- Evidencia OSINT (capturas, headers, WHOIS, DNS)
- Anexos legales (si aplica)
- Entregables listos para presentación formal

## 🛠️ Herramientas utilizadas

- **SpiderFoot HX**, **Maltego CE**, **Shodan**, **WhoisXML API**
- **Google Dorks**, **Wayback Machine**, **HaveIBeenPwned**
- **VirusTotal**, **Audacity**, **OBS Studio**, **Canva**, **Notion**

## 📁 Casos de estudio

Este sitio incluye ejemplos reales (anonimizados) de investigaciones OSINT aplicadas a:
- Denuncias de fraude digital
- Auditorías reputacionales en plataformas fintech
- Cursos impartidos a periodistas y equipos legales

## 🌐 Estructura del sitio

- `index.html`: Página principal
- `servicios.html`: Fichas detalladas de cada servicio
- `casos.html`: Portafolio de investigaciones
- `herramientas.html`: Stack técnico y metodologías
- `contacto.html`: Formulario de contratación y enlaces de pago
